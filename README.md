# SOBO / MatOpt

材料配方单目标贝叶斯优化静态 Web MVP。

当前版本按 MatOpt 配方优化工作台 UI 重构，包含三栏布局：

- 左侧：目标设置、组分边界、约束条件、采集函数参数
- 中间：关键指标、代理模型曲线、EI 热图、收敛曲线、不确定性图、配方编辑器、历史实验表
- 右侧：下一组推荐配方卡片，支持应用到编辑器和标记待实验

## 运行

直接用浏览器打开 `index.html` 即可，无需安装依赖。

## 主要交互

- 运行迭代：刷新候选排序、预算和图表
- 应用候选：把右侧推荐配方写入中间编辑器
- 编辑配方：输入框、步进按钮和滑块联动
- 归一化：按未锁定组分把总和调整到 100%
- 添加实验结果：回填 Tg 并更新历史最佳
- 导出：下载历史实验 CSV
