# SOBO

材料配方单目标贝叶斯优化 MVP。

当前版本是一个无构建依赖的静态 Web 原型，聚焦聚合物/树脂配方优化闭环：

- 项目仪表盘、目标方向、项目状态和关键指标概览
- 历史实验数据表、当前最佳配方和 Tg 趋势/分布可视化
- 配方比例约束校验、重复配方校验和可查看的校验详情
- 生成 1-20 范围内的下一轮候选配方示例逻辑
- 候选转实验、CSV 导入历史实验、CSV 导出候选结果

## 运行

直接用浏览器打开 `index.html` 即可。

CSV 导入列名要求：

```csv
epoxy,curing,toughener,filler,diluent,tg,round
45,25,10,12,8,148.6,7
```
